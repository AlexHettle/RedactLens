## Optional software not distributed with RedactLens

RedactLens can connect to an Ollama service running locally, but the Ollama
application and AI model weights are not included in the RedactLens
installer. Users obtain them separately and those downloads are governed by
their own terms. In particular, the recommended Qwen3-Coder model is published
separately under the Apache License 2.0.

## Reporting an omission

This file is maintained with the Windows dependency lock files. If you believe
a component or required notice is missing, please open an issue before
redistributing the affected build.
